# AI Innovation Club Website

A modern, responsive website developed for the **AI & Innovation Club**, showcasing artificial intelligence, machine learning projects, prompt engineering workshops, innovation challenges, and club activities. The project demonstrates modern front-end web development techniques using HTML5, CSS3, JavaScript, jQuery, Bootstrap, browser storage technologies, RESTful API integration, and social media plugins.

> **Course:** UCCD2323 Front-End Web Development  
> **Institution:** Universiti Tunku Abdul Rahman (UTAR)

---

## Project Overview

The objective of this project is to design and develop a mobile-responsive club website that provides users with information about AI-related events, projects, workshops, and membership opportunities while demonstrating modern front-end development technologies.

The website emphasizes:
- Responsive and user-friendly UI/UX
- Interactive web components
- Browser storage technologies
- RESTful API integration
- Dynamic content
- Modern web development best practices

---

## Technologies Used

| Technology | Purpose |
|------------|---------|
| HTML5 | Website structure and semantic elements |
| CSS3 | Styling, animations, transitions, and responsive layouts |
| Bootstrap 5 | Responsive grid system and reusable UI components |
| JavaScript (ES6) | Interactive website functionality |
| jQuery | DOM manipulation, AJAX, animations, and event handling |
| RESTful API | Retrieve dynamic AI-related information |
| Cookies | Store user preferences (e.g., dark mode, cookie consent) |
| Local Storage | Store persistent user preferences and favorite items |
| Session Storage | Store temporary user data such as form drafts |
| Social Media Plugins | Integrate Google Maps, YouTube, and social media links |
